# Инструкция к применению

1. Скачать MurIDE вместе с симулятором по ссылке https://murproject.com версии 0.1.1 или скачать последнюю версию симулятора отдельно с репозитория https://github.com/murproject/mur_simulator.
2. Скачать все файлы из репозитория. В репозитории находятся файлы Scene_v1.xml и Scene_v1.xml, содержащие всю информацию о сцене, а также папка CustomResources, содержащая текстуры, материалы, и другие ресурсы, использующиеся сценами.
3. Перенести папку CustomResources репозитория по пути: ...\MurIDE\resources\simulator
4. Открыть Scene_v1.xml или Scene_v2.xml в MUR Simulator
